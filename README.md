# RoboKids — Children's Robotics School (Lab 9)

Landing page: `index.html`, `style.css`, `images/`.

## Git & GitHub Pages

```bash
git init -b main
git add index.html
git commit -m "feat: add semantic html structure"
git add style.css
git commit -m "feat: add responsive grid layout and burger menu"
git add images README.md
git commit -m "feat: add svg assets and readme"
git remote add origin https://github.com/<Azali-ark>/robokids-landing.git
git push -u origin main
```

Then: Settings → Pages → Source: `main` / root.
